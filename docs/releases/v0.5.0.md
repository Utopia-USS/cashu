## cashU 0.5.0 - nowa aplikacja na macOS

Pierwsze wydanie nowej, natywnej aplikacji cashU. Zastępuje dotychczasową aplikację w Pythonie: te same
funkcje (budżet, majątek, kredyty, inwestycje, agent AI przez MCP), a dane każdego profilu są teraz
zaszyfrowane, z kluczem w pęku kluczy macOS i 24-wyrazową frazą odzyskiwania. Wszystko nadal działa
lokalnie. Aplikacja jest podpisana i notaryzowana przez Apple, a kolejne wersje instaluje sama
(Ustawienia > Aktualizacje).

**Pobierz:** `cashU-0.5.0-mac-arm64.dmg` (Apple Silicon) albo `cashU-0.5.0-mac-x64.dmg` (Intel).
Wymaga macOS 13 lub nowszego.

**Masz starą aplikację cashU?**

1. Zamknij starą aplikację, otwórz pobrany dmg i przeciągnij cashU do Aplikacji, zastępując starą.
2. Przy pierwszym uruchomieniu kliknij „Zaimportuj moje dane”. Import przenosi wszystkie profile na
   miejscu i zachowuje oryginalne pliki w folderze kopii zapasowej. Zapisz na papierze nową frazę
   odzyskiwania.
3. Stare zadania w tle aplikacja usuwa sama. Jeśli używasz Claude Code, uruchom pokazane po imporcie
   polecenia `claude mcp remove` / `claude mcp add` (przycisk „Kopiuj”), aby podłączyć agenta do nowej
   aplikacji.

Stara aplikacja nie zaktualizuje się sama: pokaże tylko kartę „Nowa wersja 0.5.0”, a „Aktualizuj” ją
zamyka. Pobierz nową wersję z tej strony.

## cashU 0.5.0 - the new macOS app

The first release of the new, native cashU app. It replaces the Python app: the same features (budget,
assets, loans, investments, the AI agent over MCP), and each profile's data is now encrypted, with its
key in the macOS keychain and a 24-word recovery phrase. Everything still runs locally. The app is signed
and notarized by Apple and installs later versions itself (Settings > Updates).

**Download:** `cashU-0.5.0-mac-arm64.dmg` (Apple silicon) or `cashU-0.5.0-mac-x64.dmg` (Intel).
Requires macOS 13 or later.

**Using the old cashU app?**

1. Quit the old app, open the downloaded dmg and drag cashU to Applications, replacing the old one.
2. On the first start click "Import my data". It moves every profile over in place and keeps the
   original files in a backup folder. Write the new recovery phrase down on paper.
3. The app removes the old background agents itself. If you use Claude Code, run the
   `claude mcp remove` / `claude mcp add` lines the finished import shows ("Copy" button) to connect
   your agent to the new app.

The old app does not update itself: it only shows a "New version 0.5.0" card, and "Update" closes it.
Download the new version from this page.
